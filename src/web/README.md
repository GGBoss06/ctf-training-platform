# Web 应用

Flask + Jinja2 + 原生 HTML/CSS/JavaScript，连接 MySQL。包含登录、注册、题库、详情、个人中心、排行榜、题目管理、录题、修改、用户管理、账号管理、日志等 12 类页面。

本实现取代旧初稿中未完成的 ASP.NET 示例；判定和计分仍由 MySQL 存储过程与触发器完成。

- app.py：路由、校验、会话、权限、CSRF。
- db.py：每请求连接、参数化查询、存储过程调用。
- templates/：Jinja2 页面。
- static/：样式与前端交互。

管理员可删除任意状态的题目（含已有提交与得分记录，按外键顺序连带清理并在操作日志留痕），可在「用户管理 → 管理账号」中修改学生邮箱与状态、重置登录密码、删除账号（提交、解题、得分与操作日志随账号清理）。管理员账号受保护，不能在用户管理中修改或删除。

运行步骤见根目录 README。
