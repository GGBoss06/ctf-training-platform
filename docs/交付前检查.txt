一、本人电子签
1. 打开 01_系统设计报告 中的 Word 文件，在封面插入本人电子签名。
2. 用签署后的 Word 重新导出同名 PDF，替换原 PDF。

二、通过本机 GitHub Desktop 推送
1. 先解压整个压缩包。
2. GitHub Desktop → File → Add Local Repository。
3. 选择 02_程序源代码/ctf-training-platform 文件夹。
4. 确认远程为 GGBoss06/ctf-training-platform、当前分支为 main。
5. 如果修改了签名，使用 docs(report): 补充本人电子签与最终报告 作为提交说明，并点击 Commit to main。
6. 点击 Push origin。交付包中准备的新增提交会一起推送。
7. 打开 GitHub 网页核对提交总数至少 20，并确认有最终代码、Word 和 PDF。
8. 若提示远程已有新提交，不要 Force push；保留两份项目后合并处理。
